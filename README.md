# 🍗 BigBite Grill Web Platform

A responsive multi-outlet food service web application built to showcase menu offerings, manage customer engagement portals, and streamline order coordination across Abuja locations. Developed as part of the COS 106 Practical Term Project.

---

## ✨ Features

* **Interactive Menu Showcase:** Highlight signature chicken grills and delicious side dishes.
* **Multi-Outlet Directory:** Seamlessly view and locate active branches across Abuja.
* **Direct Order Coordination:** Integrated contact channels linking customers directly to pick-up, walk-in, and delivery services.
* **Responsive Design:** Fully optimized layout ensuring a smooth user experience across desktop and mobile devices.

---

## 📍 Outlets & Locations

* **Kubwa Outlet:** Paulad Sports Centre, Kubwa FO1 (Opposite Daughter of Charity Hospital), Abuja.
* **Dutse Outlet:** White House, Dutse (Before Police Signboard), Abuja.
